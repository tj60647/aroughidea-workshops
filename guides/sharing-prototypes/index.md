# Sharing AI Prototypes: A Production Pipeline

**A prototype that others can open changes the conversation.** People stop imagining your idea and start using it, and what they do tells you more than what they say. In this workshop, you move a prototype out of AI Studio and onto the web. You describe it in AI Studio, publish it to GitHub, and deploy it with Vercel, so anyone with the address can try it. There are many ways to make things with AI. This workshop uses one popular set of tools, and the pattern carries over to many others. The tools change quickly, so a button may look different when you read this, but the steps stay the same.

The pipeline has two halves:

1. **AI Studio → GitHub:** AI Studio publishes your app's files to GitHub.
2. **GitHub → Vercel → the world:** Vercel picks up those files and puts them online.

---

## What You'll Do

- Create GitHub and Vercel accounts, if you don't have them yet.
- Publish an app from AI Studio to GitHub, and deploy it with Vercel.
- Change the app, and watch the change reach the live address.
- Share the address, and try someone else's app.
- Get an API key, so an app that uses AI works on Vercel too.

---

## Before You Start

You'll need:

- **A computer with a web browser** and an internet connection.
- **A Google account for AI Studio.** Use a personal Google account if your school's account blocks the tool.
- **A basic app in AI Studio,** such as the one from Workshop 3's practice. Start with one that doesn't need an API key.
- **Your agent from Workshop 3,** for the second half, where you add an API key.

[Workshop 3: AI as a Tool](/ai-as-tool/) shows how to build an app in AI Studio. If you haven't made one yet, start there.
